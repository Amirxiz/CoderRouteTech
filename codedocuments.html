BlockzGame Code

Section 1: Make a cube

cubePlayer {
    grid(1x, 1y)
    index(1)
}

cubePlayer creates a named cube. grid(1x, 1y) places it at column 1, row 1. index(1) gives it an index so it can be selected and controlled.

Section 2: Change a cube's color

cubePlayer {
    grid(4x, 6y)
    bg-color: lime
    index(1)
}

bg-color sets the cube's background color. You can use a color name, such as lime, or a hex value such as #7dd3a7.

Section 3: Reuse a class

create class(wall)

.wall {
    bg-color: slategray;
    border-collision: true;
}

cubeWall {
    grid(8x, 4y)
    class: wall
    index(none)
}

A class groups shared cube settings. Applying class: wall gives the cube those settings. index(none) makes it an unselectable NPC cube.

Section 4: Turn on collision

import collision

This enables collision checks in BlockzGame. Cubes with border-collision: true can block another cube from moving onto their grid position.

Section 5: Move your cube

cubePlayer {
    grid(2x, 2y)
    index(1)
}

Use W, A, S, and D to move the selected cube. Press E to switch between indexed cubes.

HTML Code Basics

Section 1: Basics

<!DOCTYPE html>

<!DOCTYPE html> tells the browser the document uses modern HTML. It belongs at the very beginning of an HTML page.

Section 2: The HTML page

<html lang="en">
    <head>
        <title>My first page</title>
    </head>
    <body>
        Page content goes here.
    </body>
</html>

<html> wraps the page. The <head> contains page information, while the visible content goes inside <body>. The lang attribute identifies the page language.

Section 3: Headings and paragraphs

<h1>Welcome</h1>
<p>This is a paragraph.</p>

<h1> is the main heading. Use paragraph tags, <p>, for blocks of regular text.

Section 4: Links

<a href="https://example.com">
    Visit Example
</a>

The <a> element creates a link. Its href attribute says where the link goes, and the text between the tags is clickable.

Section 5: Lists

<ul>
    <li>First item</li>
    <li>Second item</li>
</ul>

<ul> makes a bulleted list, and each <li> is one list item.
